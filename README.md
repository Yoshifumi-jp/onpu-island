# おんぷアイランド

小学校低学年向けの音楽学習Webアプリです。島をめぐるゲームで、楽譜の読み方とリズム・拍子を、見て・聞いて・たたいて覚えます。

- あそぶ：https://yoshifumi-jp.github.io/onpu-island/
- 版：v0.6.1
- 動作環境：iPad（Safari／Chrome）、Androidタブレット（Chrome）、Windows（Chrome／Edge）の新しい版

## 方針
- インストール・登録不要。広告・課金なし
- 外部へのデータ送信なし。記録はお使いの端末の中（ブラウザ）だけに保存
- 使い方は、はじめる画面の右下［おうちの方へ］から読めます
